Storage / offline probe

Temporary diagnostic (P0). Uses only its own stores: IndexedDB "guya_probe", Cache "guya-probe-v1", localStorage keys "guya_probe_*", and a service worker limited to this probe/ folder. It does not read or write any Guya app data. Nothing is sent anywhere.
How to run it
  1. Open this page from the home-screen Guya (Storage check, section 7).
  2. Tap Run write tests. Wait for "done".
  3. Reload this page once (second load).
  4. Force-close Guya, reopen, come back here (blob and cache re-verify).
  5. Turn on Airplane Mode, reload this page (offline serve).
  6. Tap Copy report after each step and paste it into the planning chat.
